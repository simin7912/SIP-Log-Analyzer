About Universal SIP & Multi-Protocol Log Analyzer

The Universal SIP Log Analyzer is a robust, web-based diagnostic utility specifically designed for telecommunications engineers, VoIP developers, and network administrators. Dealing with raw SIP logs and packet captures can be a daunting task, especially when diagnosing complex routing issues across multiple nodes. This tool automatically parses large log files, extracts SIP signaling messages, and reconstructs the entire communication flow into intuitive sequence diagrams. By shifting the processing power entirely to your local browser, it guarantees complete privacy and security—your sensitive telecommunications data never leaves your machine.

Most commercial SIP analyzers require a paid license, a desktop install, or an upload to a third-party server before you can even see a call flow. This project started from a simple frustration: on-call engineers debugging a live outage at 2 a.m. rarely have time for any of that. Every parsing rule here — from Call-ID grouping to codec negotiation extraction — was built directly from real-world carrier interconnect logs, SBC traces, and PBX registration failures, so the tool focuses on the signaling patterns engineers actually run into rather than a theoretical RFC checklist. See the SIP protocol guide and NAT one-way audio guide below for the reasoning behind each check.

Key Features

  • CallHalf & Call-ID Sequence Diagram: Visualizes complex call flows with intuitive nodes and arrows.
  • RFC 3261 Compliance Inspector: Real-time checks for missing headers, NAT one-way audio risks, and provisional reliability.
  • Multi-Session Merge: Combine multiple related call sessions into a single unified sequence diagram.

How to Use

Click the [Upload Log] button or try the [Load Sample] button to test the analyzer instantly.

  1. Upload your standard log file (text format containing SIP messages).
  2. Use the search and filter panel to locate specific phone numbers, IP addresses, or SIP URI.
  3. Select a session from the sidebar to generate the sequence flow diagram.
  4. Click on any signaling arrow to inspect the raw, colorized SIP payload and SDP negotiation details.

Frequently Asked Questions

Is my log file uploaded to a server?

No. Parsing happens entirely in your browser using JavaScript. The file never leaves your machine, which makes this tool suitable for logs containing real subscriber numbers or internal IP addressing.

What log formats are supported?

Plain-text logs containing standard SIP request/response messages (INVITE, REGISTER, SUBSCRIBE, OPTIONS, REFER, etc.), including SDP bodies. Most SBC, PBX, and softswitch debug exports work with little or no reformatting.

Does this replace Wireshark?

Not for packet-level troubleshooting. This tool is aimed at reading already-captured application logs quickly and turning them into a readable call flow, rather than capturing raw traffic.
